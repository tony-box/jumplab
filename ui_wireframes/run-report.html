Run report

One solved run read against a pinned baseline. Pure output: no inputs, no solver, no new state — two RunResult objects rendered as headline deltas, four charts, two tables and a published accuracy bound. This is the screen a rider screenshots to argue about technique, so every number has to say where it came from.

Delta rules

  • No baseline ⇒ no delta. Blank cells, not zeros, and the Δ column header dims.
  • Direction is per-metric, not global. Airtime, apex and distance read higher-is-larger. Landing attitude and energy residual are best near zero; impact speed is neutral. Encode this as a polarity: 'up' | 'down' | 'zero' | 'none' field per metric rather than colouring by sign.
  • Show the unit on the delta. +0.14 s, not +0.14. Percentages only where the base quantity has a meaningful zero.
  • Never delta across sources. A measured run against an estimate baseline renders the delta with the weaker source's marker, so nobody reads it as a precise result.
  • Colour is a secondary channel. Sign and unit carry the meaning in text; the tint only reinforces it. Deltas must stay legible in greyscale print.

Chart conventions

RuleWhy
Axis labels sit outside the plot rect, with the tick band reservedThe first build overlapped labels with tick values; reserve a gutter rather than nudging text.
Shared y-domain between run and baselineTwo different scales makes a visual comparison a lie.
Filled area under the run trace at low alphaOutline-only charts read as unfinished and lose the sign of the quantity at a glance.
Phase shading behind the plot (air vs contact)Lets a reader see which part of a curve is ballistic without cross-referencing the timeline.
Fixed viewBox, preserveAspectRatio="none", no canvasCharts must stay crisp when a rider zooms the page or prints the report.
Every chart has role="img" and an aria-labelThe tables are the accessible representation; the label states what the picture shows.

States to build

StateWhat the screen shows
No baselineCharts draw one trace, Δ column blank and dimmed, headline cards drop the delta line rather than showing +0.00.
Same run both sidesExplicit hint that run and baseline are identical; deltas blank. Do not render a table of zeros.
Run not foundEmpty state with the run id, a line explaining that runs are session-scoped, and a link back to the workbench.
Pending core rowsPeak wheel load, motor work, contact impulse and solver error render blank with awaiting core in the source column. Layout must not shift when they later populate.
PrintCharts and tables survive a print stylesheet: no dark chrome, ≥12pt body, page breaks between sections, deltas legible without colour.

Acceptance checks

  • With no baseline selected, no Δ cell and no headline delta line renders a number.
  • The attitude delta is never coloured as an improvement purely because it is positive.
  • Axis labels never overlap tick values at any container width from 360px to 1440px.
  • Every chart plots both series on one shared y-domain.
  • No accuracy bound prints an exact zero; sub-precision results are worded, not rounded to 0.00.
  • Exported CSV row count equals run.frames.length and the header row names SI units.
