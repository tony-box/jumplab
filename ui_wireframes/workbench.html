Interaction contract

Solve cycle

  • Editing never solves. Rail changes update the terrain preview and mark the scenario dirty. Physics runs only on the primary action.
  • Solving is cancellable. A second solve request aborts the in-flight one; the worker discards the stale runId rather than racing it to the store.
  • Results are immutable. RunResult lands in the store once. Playback, overlays, camera and pinning all read it without mutation.
  • Failure is legible. A worker error swaps the core pill to warn tone and puts the message on the stage — the metrics rail returns to —, it does not keep stale numbers from the previous run.

Playback

  • 60fps replay, fixed-step physics. The painter interpolates between the two frames bracketing the playback clock; it never advances the simulation.
  • Slow motion scales the clock only. 0.1× shows the same frames over ten times the wall clock — no re-solve, no resampling.
  • Frame stepping is exact. ←/→ move one index. The badge frame counter is the ground truth the user checks against.
  • Playhead and scrubber share one index. Dragging the scrubber pauses playback and does not accumulate float error.

The overflow trap. This is a three-column grid whose centre column holds a wide toolbar and a wide transport row. Both the grid columns and every flex child need min-width:0, and the chipsets must wrap rather than scroll. The prototype clipped the zoom button and the Pin as baseline label twice before those two rules were applied — expect the same failure if they are dropped.

Acceptance checks

  • Solving the same scenario twice yields an identical scenarioHash and byte-identical frames.
  • Stepping forward n frames then back n returns to the exact starting index and identical badge readouts.
  • With no baseline pinned, no Δ cell renders a number — they are blank, not 0.00.
  • All four From solver core rows stay blank while the stub worker is in use, and the warning row explaining why is visible without scrolling the rail to its end.
  • At 1024px, 1280px, 1440px and 1920px there is no horizontal scrollbar and no clipped control in either rail or the transport row.
  • Every toolbar toggle is reachable by keyboard, and the focus ring is visible on the dark stage as well as the light chrome.
  • Resizing the window mid-playback does not change the frame index or re-enter the solver.
