Order is the acceptance criterion, not the absolute error. A first-order integrator halves its error when Δt halves, so the observed order should sit near 1.0. A number drifting toward 0 means the error is dominated by something other than the timestep — usually a constraint that is not converging — and that is the failure worth catching.
