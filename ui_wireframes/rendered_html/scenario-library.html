Versioned presets shared between web/ and physics/. Every jump card's entry-speed window is solved from its own geometry when this page loads — it is a property of the feature, not a note someone typed.

How the window is solved. For each feature the ballistic arc is integrated at 0.05 m/s increments from the lip. A speed is inside the window when the wheel touches down between 0.40 m past the knuckle and 0.40 m before the landing runs out. The marker shows the geometric centre of that window — the speed the feature was shaped for.
